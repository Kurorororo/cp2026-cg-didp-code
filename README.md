# Code Appendix for "Column Generation with Domain-Independent Dynamic Programming"

- didp-rs: didp-rs with new features implemented (**these features are implemented in didp-rs 0.11.1**).
- vrpbap: shared B&P code for VRPTW and PDPTW.
- vrptw: model code for VRPTW.
- pdptw: model code for PDPTW.
- pmwc: model code and instances for parallel machine scheduling.
- mrasp: model code for MRASP.
